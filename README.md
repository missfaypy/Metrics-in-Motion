# running-data-analysis
Exploratory Data Analysis of running performance data
This study examines running data recorded over two seasons to investigate how elevation gain, distance, and time of day influence running pace and energy expenditure. The dataset was analyzed in Python to uncover patterns and correlations between physiological performance and training metrics. The aim of this work is to demonstrate how personal sports tracking data can be used to derive meaningful insights into individual performance and training behavior across different conditions.
